# 公开仓库净室重写

本地的 `personthink` 只作私人对照，不进入公开历史。公开仓库里的羽师AI通用PPT生成器按 `docs/业务需求/产品/` 的决定重新实现，不迁入对照材料中的目录、接口、提示词、夹具、文案和界面。

可以保留的产品主张只有三条：生成页面之前先确认大纲；内容模型与渲染分离；导出原生可编辑 PPTX。模块怎么切、数据怎么建模、界面怎么走，以本仓库的需求、架构和功能模块文档为准。

## 考虑过的选项

- 在对照实现上改名后公开：读起来仍是同一份教程作品，不能当作羽师自己的长期资产。

## 后果

实现时以需求文档为输入。需要核对行为时可以看本地对照，但不把对照代码复制进公开仓库。
