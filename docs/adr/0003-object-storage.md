# 文件放在 S3 兼容对象存储

上传文档、使用者放入的图片、导出的 PPTX 都存放在对象存储中。程序只按 S3 兼容协议访问。演示站使用羽师配置的桶；自行部署的人更换端点、密钥和桶名。应用服务器磁盘不是这些文件的正式存放处。

桶不公开读取。下载时先核对稿件归属，再签发短时有效的读取地址。稿件只保存对文件的引用。

## 考虑过的选项

- 只放在应用服务器磁盘：部署换机器或扩成多个进程时，文件会丢或读不到。羽师已否决这一方案。

## 后果

本地开发也要有一个 S3 兼容端点（例如 MinIO），而不是再写一套「正式用磁盘」的存放方式。读取地址的有效时长由配置决定。
