# 页面生成使用 ARQ

API 与页面生成是两个 Python 进程，共用领域代码。生成进程用 ARQ 从 Redis 取出页面任务，并用 ARQ 做单页重试。某一页是否完成、稿件正文和内容模型只写在 PostgreSQL。ARQ 与 Redis 不保存稿件内容。进度经 Redis 推给 API，再由 SSE 送到界面。Redis 中的进度消息丢失后，按数据库里的未完成页重新入队。

## 考虑过的选项

- 生成进程自己轮询一张队列表：少一个依赖，但重试、并发和取任务都要自己写。羽师要求使用 Redis，并否决了自写消费者。
- Celery：能做 Redis 队列，但对异步页面生成来说更重。

## 后果

运行时至少有 API、生成进程、PostgreSQL、Redis 和对象存储。同一稿件同时生成的页面不超过 3 页；演示站的全站并发上限写在配置里。
