# 分诊标签

技能按五个标准分诊角色来表述。本文件把这些角色映射到本仓库 Issue 跟踪器实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库跟踪器中的标签 | 含义 |
| -------------------------- | -------------------- | ---- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估这条 Issue |
| `needs-info`               | `needs-info`         | 等待报告人补充信息 |
| `ready-for-agent`          | `ready-for-agent`    | 规格已完整，可供离线 Agent 接手 |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现 |
| `wontfix`                  | `wontfix`            | 不会处理 |

技能提到某个角色时（例如「打上可供离线 Agent 接手的分诊标签」），使用本表中对应的标签字符串。

若实际用词不同，修改「本仓库跟踪器中的标签」一列。
