# 01 — 愿景与范围

## 愿景

**羽师**是一份个人开源作品：把「输入主题或文档 → 确认大纲 → 生成页面 → 在线编辑 → 质量门禁 → 原生可编辑 PPTX」做成可演示、可复现、可讲述的完整闭环。

作品目标不是短期变现，而是：

1. 提供可录屏、可自用的 AI PPT 能力；
2. 作为架构与工程表达的载体，向 GitHub、B 站、公众号导流；
3. 在持续迭代中积累可信的个人作品资产。

## 产品一句话

用户给出输入主题或文档材料，先得到可修改的大纲，再生成多页内容，在编辑器中改的是同一份内容模型，最后通过质量门禁导出**原生可编辑**的 PPTX。

## 当前阶段成功标准

同时满足以下条件，即视为「可拿去引流的 MVP」成立：

- 仓库以 **MIT** 许可公开，文档与代码均以「羽师」为名叙事；
- 本地可跑通一条幸福路径（见 `04-能力清单-MVP与非目标.md`）；
- 能支撑系列课程原料的讲解与演示，而无需依赖未公开的参照课件。

## 范围内（MVP）

- 内容模型驱动的稿件（Deck）生命周期；
- 大纲确认后的页级生成与重试；
- 在线编辑写回内容模型（含锁定）；
- 导出前质量门禁；
- 原生可编辑 PPTX 导出；
- 输入：输入主题，以及 Markdown / TXT / PDF / Word；
- 配图：占位图或固定图库（不做 AI 生图链路）；
- 本地单用户使用（无注册登录）。

## 范围外（当前明确不做）

- 多用户账号体系、协同编辑、SaaS 订阅与计费；
- AI 生图 → 外链图库 → 占位的完整降级链（仅保留占位/固定图）；
- 主题/模板市场、跨页风格迁移、开放 API 商业化；
- 公网托管 Demo（可作为加分项，不阻挡 MVP 完成判定）。

## 公开叙事原则

对外（README、课程发布稿、视频口播）只讲**问题、设计抉择与羽师实现**，不绑定、不推广任何第三方商业教程品牌。对齐用的私参材料不进入公开仓库。
