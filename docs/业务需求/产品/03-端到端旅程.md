# 03 — 端到端旅程

## 总览

```text
创建稿件
   → 提供输入（输入主题 或 MD/TXT/PDF/Word）
   → 生成大纲
   → 【人工】确认 / 修改大纲
   → 页级生成（可并发、可单页重试）
   → 预览与在线编辑（写回内容模型）
   → 质量门禁
   → 导出原生可编辑 PPTX
```

两个**刻意保留的人工节点**：

1. **确认大纲** — 定叙事方向，避免方向错误后空耗生成；
2. **导出前质量门禁** — 错误级问题先拦住，再允许导出。

## 阶段说明

| 阶段 | 用户感知 | 系统要点 | 失败时 |
|------|----------|----------|--------|
| 创建稿件 | 新建一份空稿件 | 分配稿件标识与初始修订 | 可重新创建 |
| 输入 | 打主题或交文档 | 规范化文本；文档需解析抽取 | 提示格式不支持或解析失败，可改换输入 |
| 大纲 | 看到可编辑大纲 | 结构化大纲字段 | 可重新生成大纲，不自动开写正文页 |
| 确认大纲 | 明确「可以生成页面了」 | 未确认不得进入页级生成 | — |
| 页级生成 | 进度条/逐页状态 | 页任务可异步；单页可失败 | 单页重试；允许软取消未完成任务 |
| 编辑 | 改字、改块、锁定 | 只写内容模型，不落自由 HTML 终态 | 冲突时用修订信息提示刷新 |
| 门禁 | 看到错误/警告列表 | error 阻断导出；warning 可继续 | 用户修稿或降级处理后重跑 |
| 导出 | 下载 PPTX | 文本/表/图为原生可编辑对象 | 导出失败保留稿件，可重试 |

## 内容 / 布局 / 主题

全程遵守正交关系：

- **内容块**承载文案与数据；
- **布局**描述排布意图（由求解得到几何，而不是让模型直接写死精确坐标作为唯一真相）；
- **主题（Theme）**只影响视觉皮肤。

Web 预览与 PPTX 导出必须读**同一份内容模型**（同源），禁止「预览一套、导出再生成另一套文案」。

## 配图（MVP）

页面可含图片类内容块，但资源来自**占位图或固定图库**。不把「调用生图模型」当作幸福路径前置条件。

## 与课程原料的关系

旅程中每个阶段都应对得上至少一篇课程原料（见 `../课程原料/00-系列导航与篇目对照.md`），便于录屏时按阶段切分镜头。
