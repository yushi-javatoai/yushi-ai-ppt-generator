# 04 — 能力清单：MVP 与非目标

## 许可证与交付形态

| 项 | MVP 要求 |
|----|----------|
| 开源许可 | MIT |
| 运行形态 | 本地可运行；单用户 |
| 公网 Demo | 非必须 |

## 幸福路径验收（Definition of Done）

在干净环境按文档启动后，必须能录屏证明：

1. 以**输入主题**创建稿件；
2. 生成并**修改后确认**大纲；
3. 生成 **≥ 5** 页，进度可见；
4. 在编辑器修改至少一处正文，保存后再次打开仍在；
5. 将某块**锁定**后，再生成类操作不覆盖该块；
6. 质量门禁跑出明确结果；无 error 时可导出；
7. 所得 PPTX 在 PowerPoint 或 WPS 中**可直接编辑文字**（正文不是整页图片）。

另需抽测：**Markdown、TXT、PDF、Word** 至少各一条输入能进入「大纲确认 → 生成页面」（页数可少于主题路径的展示页数，但不得在解析成功后卡死）。

## 功能清单

### 必须有（P0）

| ID | 能力 | 说明 |
|----|------|------|
| P0-01 | 稿件 CRUD | 创建、打开、列表（本地范围即可） |
| P0-02 | 输入主题 | 短文本生成大纲 |
| P0-03 | 文档输入 | Markdown / TXT / PDF / Word |
| P0-04 | 大纲生成与确认 | 未确认不能生成正文页 |
| P0-05 | 内容模型 | 全链路唯一真相；禁止模型直接吐最终 HTML/PPTX |
| P0-06 | 页级生成 | 可并发或等价的页级任务；单页重试 |
| P0-07 | 进度与软取消 | 长任务可观察；取消不破坏已成功页 |
| P0-08 | 结构化输出与校验 | schema + 业务规则；可有限次修复 |
| P0-09 | Web 预览 | 基于内容模型渲染 |
| P0-10 | 在线编辑写回 | 编辑结果写回模型；支持锁定 |
| P0-11 | 布局与主题分离 | 换 Theme 不改写叙事文案 |
| P0-12 | 质量门禁 | error / warning；error 阻断导出 |
| P0-13 | 原生可编辑 PPTX | 文本框等可编辑；禁止截图冒充正文 |
| P0-14 | 配图占位 | 占位图或固定图库 |

### 应该有（P1，可与 P0 同迭代但不挡「可引流」对外声明）

| ID | 能力 | 说明 |
|----|------|------|
| P1-01 | 导出回读抽检 | 导出后抽样检查关键文本仍在 |
| P1-02 | 灵活排版（布局树） | 模型描述意图，系统求解几何 |
| P1-03 | 演示样例包 | 主题与各格式文档各至少 1 份 |

### 非目标（本期不做）

| ID | 能力 | 备注 |
|----|------|------|
| N-01 | 注册 / 登录 / 多租户 | 与「本地单用户」冲突 |
| N-02 | 协同编辑 | 远期 |
| N-03 | AI 生图全链路 | 有占位即可 |
| N-04 | 主题市场 / 用户自定义布局市场 | 远期 |
| N-05 | 计费、配额、商业 API | 远期 |
| N-06 | 语音 / OCR / URL 抓取输入 | 非 MVP 输入集 |
| N-07 | 必须公网部署 | 加分项 |

## 质量属性（MVP 底线）

- **可控**：方向靠大纲确认；单页可重试；锁定防覆盖。
- **可导出**：原生可编辑，而不是「只能看不能改」。
- **可讲述**：任一 P0 能力都能在课程原料中找到对应主张与演示脚本。
- **可公开**：公开仓不包含未授权的第三方课件或私参对照品牌材料。

## 明确技术中立声明

本需求**不锁定**具体框架或云厂商；实现选型另用 ADR 记录。需求只约束领域行为与验收：内容模型、人工大纲节点、门禁、原生导出、本地单用户、输入格式集合与配图策略。
