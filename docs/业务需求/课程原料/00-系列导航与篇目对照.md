# 00 — 系列导航与篇目对照

## 系列定位

面向中文开发者，用**羽师**讲清楚：如何把不可控的模型输出，变成可编辑、可校验、可原生导出的 PPT 流水线。  
每篇原料可直接拆成 B 站一集或一版公众号长文；结构固定，便于转 PPT。

## 发布原则

- 对外只讲问题、抉择与羽师实现；
- 不依赖未公开的第三方课件；
- 演示以仓库可运行行为为准。

## 篇目与产品能力映射

| 序号 | 原料文 | 一句话主张 | 主要对应产品能力 |
|------|--------|------------|------------------|
| 01 | 羽师作品全景 | 先有可控闭环，再谈「更聪明的模型」 | 愿景、幸福路径、范围 |
| 02 | 稿件单一数据源 | 中间必须有结构化稿件，而不是直接吐成品 | P0-05 |
| 03 | 预览层如何投影模型 | 预览读内容模型，拒绝第二套真相 | P0-09、P0-11 |
| 04 | 可改字的 PPTX 交付 | 导出要能改字，截图不算交付 | P0-13 |
| 05 | 分层校验与可用优先 | 格式→结构→业务分层；能用优先于完美 | P0-08、P0-14 |
| 06 | 带错修复的生成回路 | 带问题描述的修复，而不是盲重视试 | P0-08 |
| 07 | 按页拆分的长任务 | 长任务按页拆开，进度可见、可重试 | P0-06、P0-07 |
| 08 | 改稿写回与锁定 | 编辑写回模型；锁定防 AI 覆盖 | P0-10 |
| 09 | 布局意图交给求解器 | 模型管意图，系统算几何 | P1-02 |
| 10 | 导出前的分级拦截 | 导出前分级拦截 | P0-12 |
| 11 | 开源发布与本地跑通 | 本地可跑 + MIT 公开，先完成作品再谈托管 | 许可、DoD、非目标 |

## 建议拍摄 / 写作顺序

可按 01→11 连载，12–15 作周边篇；若要先冲播放，可用：**01 → 02 → 04 → 07 → 10 → 其余补齐**。

## 每篇固定模板（勿删字段）

1. 一句话主张  
2. 问题场景  
3. 错误做法  
4. 设计抉择  
5. 羽师中的对应模块  
6. 演示脚本  
7. 练习 / 作业  
8. 下期钩子  

## 演示样例（产品侧附带）

另备最少一套演示样例（主题文案 + MD/TXT/PDF/Word 各一），放在实现仓库的样例目录（实现阶段创建）；课程口播引用样例名即可。
