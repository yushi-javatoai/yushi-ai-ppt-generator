# 03 — 预览层如何投影模型

## 一句话主张

Web 预览必须是内容模型的投影；禁止在浏览器里养一份回写不了的自由 HTML 终态。

## 问题场景

演示时页面很好看，一点「保存」却存的是抽不出结构的 HTML。导出器读不到要点，只能截图——用户以为能编辑，其实不能。

## 错误做法

- 预览组件直接 `dangerously` 塞模型吐出的 HTML 字符串并以此持久化；  
- 拖拽改版面只改 DOM，不改布局描述；  
- 为「好看」在预览层写死后端导出器不认识的私货。

## 设计抉择

- 渲染器：内容模型 → 视图；  
- 编辑手势最终打成「模型补丁」；  
- 布局求解可在前端或共享层做，但结果仍挂在模型可理解的字段上；  
- 与 PPTX 导出共享同一套块类型语义。

## 羽师中的对应模块

- P0-09 Web 预览  
- P0-10 编辑写回（下一集深讲）  
- P0-11 主题分离

## 演示脚本

1. 打开预览，DevTools 或调试面板展示「当前页内容块列表」；  
2. 改主题皮肤，强调文案块还在；  
3. 故意对比「坏架构」示意：只存 HTML 时导出器两眼一抹黑；  
4. 收束：好看可以，但真相在模型。

**口播时长建议：** 10–14 分钟。
