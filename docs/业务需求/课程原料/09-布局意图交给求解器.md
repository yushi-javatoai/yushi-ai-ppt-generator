# 09 — 布局意图交给求解器

## 一句话主张

模型描述排布意图（方向、比例、间距），系统求解几何；不要让模型直接对精确坐标负责。

## 问题场景

模型输出 `x=37.2,y=12.8`，换个主题字体就全部重叠。你开始手写 if-else「修版」，永不结束。

## 错误做法

- 提示词要求模型输出绝对像素当唯一真相；  
- 每换皮肤就重新让模型「排一次版」；  
- 布局与文案耦合在同一段不可拆分文本里。

## 设计抉择

- 引入布局树或槽位等**意图层**；  
- **求解器**根据画布与测量结果产坐标；  
- 内容块不变时，可只重求解；  
- MVP 可将完整灵活排版放在 P1，但叙事上必须提前讲清原则，避免实现期走回绝对坐标迷信。

## 羽师中的对应模块

- P1-02 灵活排版  
- P0-11 布局与主题分离  
- 与 Web 渲染、导出共享几何语义

## 演示脚本

1. 同一组内容块，两种布局意图（左右 vs 上下）；  
2. 展示求解前后：意图 JSON → 盒子坐标；  
3. 换 Theme 字体后重求解，文案不改；  
4. 收束：模型管「什么关系」，系统管「多少像素」。

**口播时长建议：** 12–16 分钟。

## 练习 / 作业

用树状伪代码描述「标题 + 双栏要点」的布局意图（含方向、比例），不要写具体像素。
