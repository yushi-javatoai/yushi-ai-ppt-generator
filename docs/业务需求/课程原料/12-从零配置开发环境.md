# 12 — 从零配置开发环境

## 一句话主张

别人只靠公开文档，就能在本机跑通幸福路径；跑不起来的作品，导不了流。

## 问题场景

观众星标后 `clone`，卡在依赖、端口、模型 Key、PDF 解析库——十分钟后关页。你的 B 站再好看也变不成可复现作品。

## 错误做法

- README 只有架构图，没有复制即用的启动命令；  
- 密钥写进示例仓；  
- 「在我机器可以」当成完成标准；  
- 把私参课件路径写进公开步骤。

## 设计抉择

- 一份「快速开始」：环境前提、安装、配置模板（`.env.example`）、启动、验收勾选；  
- 幸福路径 7 步与产品 DoD 对齐；  
- 文档中的路径、端口、命令以 Linux 为主（本仓库约定环境），如需跨平台另开章节；  
- 失败常见表：端口占用、Key 缺失、文档解析依赖未装。

## 羽师中的对应模块

- 产品 `04` DoD 与本地单用户  
- 课程 `11` 开源发布与本地跑通  
- 非目标：不强制公网 Demo

## 演示脚本

1. 空目录 clone（或演示等价步骤）；  
2. 复制环境模板，填最小配置；  
3. 启动后只做「主题 → 大纲确认 → 导出」缩短版；  
4. 打开 PPTX 改一个字，证明验收。

**口播时长建议：** 10–15 分钟（可做长教程）。

## 练习 / 作业

让一位没用过本仓的朋友按 README 操作；记录他卡住的前三个点，并改文档。
